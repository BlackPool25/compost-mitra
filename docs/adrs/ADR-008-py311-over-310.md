# ADR-008: Standardization on Python 3.11 over 3.10

- **Status:** Accepted
- **Date:** 2026-10-02
- **Decision:** Standardizes runtime on Python 3.11 across Windows, Linux, and Docker CI.
- **Consequences:** Yields 10-20% interpreter speedups and stable cross-platform wheel builds.
