# ADR-001: Streamlit Prototype over React + FastAPI

- **Status:** Accepted
- **Date:** 2026-10-02
- **Decision:** Streamlit prototype chosen over React + FastAPI to guarantee ₹0 cost, zero node_modules, and <3s cold offline load.
- **Consequences:** Eliminates web networking, single-language Python 3.11 stack.
